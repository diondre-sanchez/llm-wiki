# Marp

Marp is a markdown-based slide deck format that allows presentations to be authored as plain text. It integrates with Obsidian through a dedicated plugin, enabling users to generate slide decks directly from wiki content without leaving the knowledge base environment.

## Overview

Marp provides a lightweight, text-based approach to creating presentations. Unlike traditional slide software, it relies on markdown syntax to define slides, making it easy to version control and integrate into text-centric workflows. In the context of the LLM Wiki pattern, Marp serves as one of several output formats for query results, alongside markdown pages, comparison tables, charts, and canvases [[LLM Wiki Pattern]].

## Key Facts

- **Format**: Markdown-based slide deck format.
- **Integration**: Has a dedicated plugin for Obsidian.
- **Use Case**: Generating presentations directly from wiki content [[LLM Wiki Pattern]].
- **Context**: Mentioned as a tip for enhancing the LLM Wiki workflow, specifically for converting accumulated knowledge into presentable formats [[LLM Wiki Pattern]].

## Relationships

- **Obsidian**: Marp is used within Obsidian via a plugin, leveraging the platform's markdown ecosystem [[Obsidian]].
- **LLM Wiki Pattern**: Marp is cited as a recommended tool for outputting query results as slide decks, allowing explorations and analyses to be shared in a presentation format [[LLM Wiki Pattern]].
