# Tolkien Gateway

Tolkien Gateway is a community-maintained fan wiki covering J.R.R. Tolkien's works. In the LLM Wiki pattern it is cited as a concrete example of the kind of rich, interlinked companion wiki one could build personally while reading a book, with the LLM doing the cross-referencing and maintenance. [[LLM Wiki Pattern]]

## Overview

Tolkien Gateway is a volunteer-run wiki dedicated to Tolkien's legendarium. It is described as having "thousands of interlinked pages covering characters, places, events, languages, built by a community of volunteers over years." [[LLM Wiki Pattern]]

## Role in the LLM Wiki Pattern

It appears in the source as an illustration of the **Reading a book** use case. The pattern proposes filing each chapter as you go and building out pages for characters, themes, plot threads, and how they connect, so that by the end you have a rich companion wiki. Tolkien Gateway is the benchmark for what that end state looks like at scale. [[LLM Wiki Pattern]]

The key contrast the source draws: a fan wiki like Tolkien Gateway is built by a community of volunteers over years, whereas the LLM Wiki pattern lets a single person build something comparable personally as they read, with the LLM handling the cross-referencing and maintenance that normally makes such a project unsustainable for one person. [[LLM Wiki Pattern]]
