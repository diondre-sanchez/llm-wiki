# Obsidian

## Overview

Obsidian is a markdown-based knowledge management application that serves as the primary interface for browsing, linking, and visualizing the wiki. In the author's analogy, Obsidian functions as the IDE while the LLM acts as the programmer and the wiki is the codebase [[LLM Wiki Pattern]]. It provides the visual and structural layer that makes the LLM-maintained knowledge base navigable and inspectable in real time.

## Key Features

- **Graph View**: The best way to see the shape of the wiki, revealing what is connected to what, which pages are hubs, and which are orphans [[LLM Wiki Pattern]].
- **Web Clipper**: A browser extension that converts web articles to markdown, useful for quickly getting sources into the raw collection [[LLM Wiki Pattern]].
- **Local Image Handling**: Settings allow configuring an attachment folder path (e.g., `raw/assets/`) and binding a hotkey to download attachments for the current file, enabling the LLM to view and reference images directly instead of relying on potentially broken URLs [[LLM Wiki Pattern]].
- **Plugin Ecosystem**: Supports plugins that extend functionality, including [[Marp]] for slide decks and [[Dataview]] for querying page frontmatter [[LLM Wiki Pattern]].

## Role in the LLM Wiki Pattern

Obsidian is used alongside the LLM agent during the workflow. The author typically has the LLM agent open on one side and Obsidian on the other, allowing them to browse results in real time, follow links, check the graph view, and read updated pages as the LLM makes edits [[LLM Wiki Pattern]]. This setup enables immediate visual feedback on the compounding knowledge structure.

## Relationships

- **[[LLM Wiki Pattern]]**: Obsidian is the designated tool for viewing and interacting with the wiki generated by this pattern.
- **[[Dataview]]**: An Obsidian plugin used to run queries over page frontmatter, generating dynamic tables and lists from wiki metadata.
- **[[Marp]]**: A markdown-based slide deck format supported via an Obsidian plugin, allowing presentations to be generated directly from wiki content.
